# DummyBankSystem

プレミアムなグラスモフィズム（透過ガラス効果）デザインを採用した、Webベースのオンラインバンキングシステムシミュレータです。
HTML、CSS（Vanilla）、JavaScript のみで構築されており、環境構築不要でブラウザ上で即座に動作します。GitHub Pages等でのホスティングや、ポートフォリオ用のデモとして最適です。

![Main View Mockup](https://raw.githubusercontent.com/dummy/url/main/mockup.png) <!-- プレースホルダー -->

## 💎 特徴

- **グラスモフィズムUI & アニメーション**: 磨りガラス効果のカード、スムーズな画面遷移フェード、処理完了時のサクセスアニメーションを搭載。
- **送金シミュレーション (お振込・振替)**: 
  - 振込先口座番号と支店コードから受取人名義を自動で確認するフローを再現。
  - 残高連動、取引履歴への自動仕訳記録。
- **定期預金・積立定期預金**: 
  - 定期・積立の契約状況を一覧表示、アコーディオンで詳細が展開。
  - 新規預入時の適用金利シミュレーション（預入期間 6ヶ月〜5年、金利 0.10%〜0.25% が動的に変化）。
  - いつでも中途解約ができ、解約資金が普通預金にリアルタイムで払い戻されるロジックを実装。
- **2段階認証設定 (SMS認証)**:
  - 携帯電話番号の登録フォーム。
  - 認証コード送信時に、ブラウザ上で**SMSメッセージ受信ポップアップ**が擬似的に起動し、発行された6桁コードを確認可能。
  - 60秒の再送信抑制カウントダウンタイマー。
- **マルチユーザー対応**: デモユーザー（`test` / `guest`）の切り替えログインに対応し、ユーザーごとに異なる残高・取引履歴・定期契約・2FA状況がロードされます。

## 🚀 はじめ方

本プロジェクトはビルドやサーバー構築が不要な静的Webアプリケーションです。

### 1. ローカルで実行する
リポジトリをクローンまたはダウンロードし、ブラウザで直接 `index.html` を開くだけで動作します。

```bash
git clone https://github.com/YOUR_GITHUB_ACCOUNT/DummyBankSystem.git
cd DummyBankSystem
open index.html
```

### 2. GitHub Pages で公開する
GitHubにプッシュした後、リポジトリの設定（Settings > Pages）から公開設定を有効にすることで、インターネット上に即時ホスティング可能です。
